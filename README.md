# Akilidex Mall

This is a responsive grocery web app built with React and TypeScript.

# Features

It shows a grid of grocery items that changes size based on your screen. You can search for products by location and sort them by price.
It also has a save button to favorite items. The app works well on both desktop and mobile phones.

# Limitations

This is a basic demo project. If I had more time I would turn it into a full shopping app.

First I would add a real cart so users can add items, change quantities and check out. I would also add user accounts so saved items and order history stay saved after a page refresh. Currently, the data resets when you reload the page which is not ideal for a real website store.
I would also create product detail pages with reviews and ratings. The current card view does not show enough information.
and finally I would improve the search tools. Right now you can only search by location. I would add search by product name and price range filters. I would also add search suggestions to make finding items much faster and easier for the user.
